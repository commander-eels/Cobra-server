Both apps run in the same stream pod on the SGIN, so they reach each other at 127.0.0.1. Both see the disks at /media, so ErsatzTV plays files straight off the drives. ErsatzTV stays LAN-only; friends outside watch the channels through Jellyfin (tv.songofeo.com).

Words used

CollectionA list you pick by hand (ticked posters).
Smart CollectionA saved search that updates itself when new files arrive.
Filler PresetA rule for breaks: where (Pre-roll, Mid-roll, Post-roll, Tail, Fallback), how much (Count, Duration, Pad), and from which list.
ScheduleWhat plays and in what order. Reusable by many channels.
PlayoutA schedule attached to a channel: the actual minute-by-minute timeline.

1.2 Version is older than 26.14.0

The pod runs the ghcr.io/ersatztv/legacy:latest image and updates itself with podman auto-update. "Legacy" is the project's name for the current, maintained ErsatzTV (a newer engine called ErsatzTV Next runs inside it). Ask Claude for the update command for the SGIN; it is not part of this guide.

1.3 Banner about JWT or IPTV disabled

ErsatzTV 26.13.0 removed stream passwords (JWT). If the old setting JWT__ISSUERSIGNINGKEY is set, the M3U and guide links are switched off. The Cobra pod script does not set it, so you should never see this. If you do, send Claude a screenshot.

2.3 No API Keys page or no + button

On Jellyfin 12 the Admin Panel icon is at the top right. API Keys is under the Advanced group of the Dashboard menu. If your screen names it differently, send Claude a screenshot.

2.9 No shows after 30 minutes

  • Check the Address is http://127.0.0.1:8096, not the songofeo.com name (that one goes through the gate login and fails).
  • Make a fresh API key (2.3) and paste it again (2.7).
  • Path problems: both containers see the drives at /media, so Edit Path Replacements is not needed. Leave it empty.
  • ErsatzTV only syncs Jellyfin Movies and Shows libraries. Filler comes in through the Local library in Part 3.

3.6 Search shows nothing

Try library_name:"Other Videos" instead. To make one list per subfolder automatically, you can also add a separate Local library per subfolder later; ask Claude.

3.8 Too many tiles to click one by one

Search first (for example a word in the file names), then tick from the results. Or skip the Commercials collection and use the All Filler smart collection in Part 5 for every row.

4.4 Red warning on the FFmpeg profile

Try Hardware Acceleration = Qsv with the same device. If both warn, the SGIN's Intel driver needs checking (manual part 3.3). Troubleshooting → Hardware tab in ErsatzTV shows what it found. Until then, None works but uses much more CPU.

5.2 Filler modes explained

CountExactly that many clips.
DurationAs many whole clips as fit in the time you set. Best for "1 to 3 ads".
PadPlays clips until the clock reaches a multiple of the minutes you set (30 = :00 and :30). Real-TV feel, longer breaks.
Mid-rollBreaks inside an episode, only at chapter marks. Most rips have none, so stay with Post-roll.

If a label on your screen differs a little from this guide (for example "Pad To Nearest Minute"), pick the closest match and send Claude a screenshot so the guide gets fixed.

7.6 No filler boxes on the schedule item

Scroll down inside the item settings; the filler boxes are below Playout Mode. If Fallback Filler is not there, set it on the channel instead (Channels → edit channel 1 → Fallback Filler).

9.3 Timeline is empty or wrong after you change things

ErsatzTV rebuilds playouts every hour and after library scans. To see changes now, open Playouts and use the Reset Playout button on that row.

10.2 What the address should look like

Only the part before :8409 changes. Keep the rest exactly as copied. Using http://10.6.9.20:8409/... also works; 127.0.0.1 just keeps the traffic inside the pod.

10.9 / 11.1 Guide is empty

  • Run Refresh Guide again (10.9) and wait 1 minute.
  • Dashboard → Live TV → the … next to XMLTV → Map Channels: click the pencil by channel 1 and pick the matching guide channel. Click the back arrow to save.

11.2 Channel spins and never plays

  • In ErsatzTV, open Channels and click the play/preview button on channel 1. If it fails there too, the FFmpeg profile is the cause (4.4).
  • If it plays in ErsatzTV but not Jellyfin, recheck the M3U address (10.2).
  • Send Claude: ErsatzTV → Troubleshooting → Playback → Upload Results; it gives an ID like etv-xxxx-xxxxxx.

11.4 Live TV missing on the Roku

Sign out and back in on the Roku Jellyfin app, and make sure that person has Allow Live TV access (11.3).

Series breaks outside Live TV

Breaks between episodes when you play a show normally (not as a channel) are a separate project: the series filler plugin. This guide only covers Live TV channels.
