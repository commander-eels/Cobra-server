1. Why these settings

The goal is direct play: Jellyfin sends the file as it is and the player decodes it. When a player can't handle the video, audio or subtitles, the SGIN has to convert the movie live (a transcode). The SGIN's Intel N5095A can do that with Quick Sync, but it costs power, can stutter with burned-in subtitles, and limits how many people watch at once. Choosing the right formats at encode time avoids almost all of it.

2. Install the Cobra presets

The file cobra-handbrake-presets.json sits next to this PDF (project files handbrake/, repo docs/handbrake/). It adds a folder named Cobra with all four presets. All four were test-encoded with HandBrake 1.7 (the NVENC one was checked for format only, since the test machine has no NVIDIA card). Newer HandBrake versions import it fine.

  1. On the-box, copy cobra-handbrake-presets.json to your Downloads folder.
  2. Open HandBrake. In the top menu bar click Presets (or the Presets button on the toolbar to show the side panel).
  3. Choose Import (Windows: Presets panel → Options or the … menu → Import from file), pick the JSON, click Open.
  4. A Cobra folder appears in the preset list. Right-click Cobra 1080p HEVC (~2 GB) → Set as default.
IF YOU CHANGE A SETTING
Edits on the tabs only apply to the current movie. To keep them, Presets → Save New Preset (give it a new name) rather than overwriting the Cobra one, so you can always go back.

4. MakeMKV: what to keep when ripping

HandBrake can only keep what MakeMKV saved. Ripping a little extra costs disk space for a day; forgetting a track means ripping the disc again.

Make MakeMKV pick these automatically

  1. MakeMKV → View → Preferences → General: tick Expert mode.
  2. Language tab: Preferred language English for both interface and tracks.
  3. Advanced tab: Default selection rule. The built-in default (favourite language, plus forced subtitles) is a good start; check the list on every disc anyway, especially that the (forced only) subtitle line is ticked.

6. Your encode, step by step

  1. On the-box, open HandBrake → Open Source → pick the MakeMKV .mkv.
  2. Preset: pick the Cobra preset from the quick card.
  3. Audio tab: confirm two tracks (Stereo AAC, Surround 5.1) from the English main audio.
  4. Subtitles tab: confirm what's listed. If the only English subs are PGS (disc subtitles), follow section 13 now, before you forget.
  5. Save As: Movie Title (Year).mp4 on a local drive.
  6. Add to Queue. Repeat for other movies, then Start Queue.
  7. When done, play the MP4 once on the-box (VLC or Films & TV): check picture, both audio tracks, subtitles.
  8. Copy to the SGIN movies folder and refresh the library (section 16).

CHANGING ASPECT RATIO MOVIES
Some films switch between widescreen and taller IMAX shots (e.g. Nolan and Marvel IMAX editions). Automatic crop would cut the IMAX shots down to the widescreen bars. For those, set Cropping to None. Use Preview to check any movie where the crop numbers look odd (for example more than 140 px off the top on a 1080p source that isn't letterboxed).

11. Hitting an exact size (bitrate tables)

When a file must fit a size, switch the Video tab to Avg Bitrate (kbps), tick Multi-Pass Encoding and Turbo first pass, and type the number from the table. The tables assume the two Cobra audio tracks (AAC 160 + AC3 640 = 800 kbps) and leave a small margin, so the result lands just under the target as Windows shows it.

Runtime1080p, 2 GB1080p, 3 GB4K, 4 GB4K, 5 GB
1 h 30 m2200380054007000
1 h 45 m1800315045005900
2 h 00 m145026503850 PRESET5050
2 h 15 m1200230033504400
2 h 30 m1000 SOFT195029003900
3 h 00 m700 TOO LOW15002300 TOO LOW3100

Numbers are video kbps. Formula for any other case:

video kbps = (target GB × 8,589,935 ÷ runtime in seconds) − audio kbps
Use about 0.1 GB less than the real target for container overhead. 8,589,935 converts Windows "GB" to kilobits.
Rule of thumbBelow this, x265 starts to look soft
1080p H.265about 1200 kbps video
4K H.265 HDRabout 3000 kbps video
LONG 4K MOVIES
A 3-hour movie at 4 GB leaves too few bits for 4K. Options: allow 5–6 GB for that one, drop the AC3 track to 448 kbps (adds ~190 kbps back to video), or make it a 1080p HEVC file, which at 4 GB looks better than a starved 4K.

Method A: turn PGS into SRT with Subtitle Edit (free)

  1. On the-box install Subtitle Edit (nikse.dk, free, Windows).
  2. Open it → File → Open → pick the MakeMKV .mkv (not the HandBrake output). Choose the English PGS track when asked.
  3. The OCR window opens. Choose Tesseract (or nOCR), language English, click Start OCR.
  4. When it finishes, click OK, then Tools → Fix common errors → Apply selected fixes.
  5. File → Save as, type SubRip (.srt), name it after the movie (table below).
  6. Repeat for the "forced only" track if you'd rather have forced lines switchable than burned.

16. Into Jellyfin, check direct play, troubleshooting

  1. Copy Movie Title (Year).mp4 (and any .srt) from the-box into the movies folder on the SGIN, inside a folder of the same name: Movie Title (Year)/.
  2. Jellyfin → Dashboard → Libraries → Movies → Scan Library.
  3. Play it on the device you care about. In the web player: gear icon → Playback Info. In the app: Dashboard → Activity while it plays.
  4. You want Direct Play. Anything else shows a reason; use the table below.
